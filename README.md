# Machine Learning Projects
## Overview

This repository contains my machine learning projects using Python, scikit-learn and TensorFlow. The projects cover different machine learning techniques, including regression, classification, data preprocessing, and model evaluation.

## Projects:

### 1. House Price Prediction

A Linear Regression project for predicting house prices based on 13 different features.

Techniques:

- Exploratory Data Analysis
- Feature scaling
- Linear Regression
- RMSE and R² evaluation
- Residual analysis

### 2. Palmer Penguins Classification

A binary classification project using Logistic Regression to distinguish between Adelie and Gentoo penguins.

Techniques:

- Exploratory Data Analysis
- One-hot encoding
- Feature scaling
- Logistic Regression
- Classification accuracy
- Confusion matrix

### 3. Telco Customer Churn Prediction

A classification project comparing Deep Learning, Random Forest, and XGBoost to predict whether telecommunications customers are likely to leave the company.

Techniques:

- Exploratory Data Analysis
- One-hot encoding
- Feature scaling
- Deep Learning, Random Forest, and XGBoost
- Classification accuracy
- Confusion matrix
