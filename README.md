# Data Science & Machine Learning Portfolio
## Overview

This portfolio showcases data science, machine learning, and time series forecasting projects using real-world datasets. Projects cover data preprocessing, exploratory data analysis, data visualization, predictive modeling, and model evaluation using Python and libraries such as pandas, scikit-learn, TensorFlow, and statsmodels.

## Projects:

### 1. House Price Prediction

A Linear Regression project for predicting house prices based on 13 different features.

Techniques:

- Exploratory Data Analysis
- Feature scaling
- Linear Regression
- RMSE and R² evaluation
- Residual analysis

### 2. Palmer Penguins Classification

A binary classification project using Logistic Regression to distinguish between Adelie and Gentoo penguins.

Techniques:

- Exploratory Data Analysis
- One-hot encoding
- Feature scaling
- Logistic Regression
- Classification accuracy
- Confusion matrix

### 3. Telco Customer Churn Prediction

A classification project comparing Deep Learning, Random Forest, and XGBoost to predict whether telecommunications customers are likely to leave the company.

Techniques:

- Exploratory Data Analysis
- One-hot encoding
- Feature scaling
- Deep Learning, Random Forest, and XGBoost
- Classification accuracy
- Confusion matrix

### 4. Stock Price Forecasting with ARIMA

A time series forecasting project predicting closing prices for 491 stocks using ARIMA models and evaluating their performance against a naive baseline.
A separate in-depth case study on Meta (META) explores ARIMA parameter optimization and evaluates whether the optimized model improves forecasting accuracy.

Techniques:

- Exploratory Data Analysis
- Feature engineering
- Stationarity testing (ADF test)
- Autocorrelation analysis (ACF/PACF)
- ARIMA time series forecasting
- Naive baseline comparison
- MAE, RMSE, and MASE evaluation
