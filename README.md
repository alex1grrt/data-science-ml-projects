# Data Science & Machine Learning Portfolio
## Overview

This portfolio showcases data science and machine learning projects using real-world datasets, covering data preprocessing, exploratory data analysis, visualization, predictive modeling, and model evaluation with Python, scikit-learn, and TensorFlow.

## Projects:

### 1. House Price Prediction

A Linear Regression project for predicting house prices based on 13 different features.

Techniques:

- Exploratory Data Analysis
- Feature scaling
- Linear Regression
- RMSE and R² evaluation
- Residual analysis

### 2. Palmer Penguins Classification

A binary classification project using Logistic Regression to distinguish between Adelie and Gentoo penguins.

Techniques:

- Exploratory Data Analysis
- One-hot encoding
- Feature scaling
- Logistic Regression
- Classification accuracy
- Confusion matrix

### 3. Telco Customer Churn Prediction

A classification project comparing Deep Learning, Random Forest, and XGBoost to predict whether telecommunications customers are likely to leave the company.

Techniques:

- Exploratory Data Analysis
- One-hot encoding
- Feature scaling
- Deep Learning, Random Forest, and XGBoost
- Classification accuracy
- Confusion matrix

### 4. Stock Price Forecasting with ARIMA

A time series forecasting project analyzing historical stock market data from 491 companies and evaluating ARIMA models against a naive baseline, with a detailed case study of Meta (META).

Techniques:

- Exploratory Data Analysis
- Feature engineering
- Stationarity testing (ADF test)
- Autocorrelation analysis (ACF/PACF)
- ARIMA time series forecasting
- Naive baseline comparison
- MAE, RMSE, and MASE evaluation
